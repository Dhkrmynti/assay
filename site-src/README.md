# Site sources

`index.html` (live home), `design-e.html` and `preview.html` (Dossier redesign, served at /preview) are generated.
Edit the files here, then run `python3 designs/build.py e` (home) or `python3 designs/build.py f` (preview).
The builder writes into the parent `ocula/` folder (path set in `build.py` as `D`).
